# 大文件快速高效比对工具 - 使用说明

## 简介
大文件快速高效比对工具是一款专门设计用于处理海量数据文件对比的桌面应用程序。该工具能够高效地比较两个超大文件（支持十亿行级别），找出两文件之间的差异，包括新增、删除和修改的记录。


## 界面功能详解

### 1. 文件选择
- **文件A**：点击按钮选择基准文件（标准文件）
- **文件B**：点击按钮选择比较文件

### 2. 基础配置选项
- **外部排序**：使用外部存储模式处理文件（适用于大文件）
- **忽略出现次数**：相同内容的记录只匹配一次
- **单线程**：使用单线程处理（较慢但资源占用少）
- **忽略行号**：比对时忽略行号位置信息

### 3. 高级配置选项

#### 主键比对
- **启用主键**：勾选以启用主键比对模式
- **主键正则**：定义用于提取主键的正则表达式
- **历史管理**：管理常用的主键正则表达式

**示例**：对于金融交易数据，可使用正则表达式 `^(.{26}).*` 提取前26位作为主键

#### 排除规则
- **启用排除**：勾选以启用排除规则
- **排除正则**：定义需要排除的行的正则表达式
- **历史管理**：管理常用的排除正则表达式

## 操作流程

### 1. 基础比对流程
1. 点击"Select File A"选择基准文件
2. 点击"Select File B"选择比较文件
3. 根据需要配置选项
4. 点击"Start Comparison"开始比对
5. 查看比对结果

### 2. 主键比对流程
1. 启用主键比对功能
2. 输入主键匹配的正则表达式
3. 选择文件并开始比对
4. 结果将显示为"修改的记录"、"缺失的记录"、"新增的记录"

### 3. 带排除规则的比对
1. 启用排除规则功能
2. 输入需要排除的正则表达式
3. 进行文件比对
4. 结果将过滤掉匹配排除规则的行

## 结果解读

### 传统比对模式（不启用主键）
- **Unique to A**：仅在文件A中存在的行
- **Unique to B**：仅在文件B中存在的行

### 主键比对模式
- **修改的数据**：主键相同但内容不同的记录对比
- **缺失的数据**：在文件A中存在但在文件B中缺失的记录
- **新增的数据**：在文件B中存在但在文件A中新增的记录

## 实际示例

以文档中的金融交易数据为例：

**标准文件**（standard_file.txt）：
```
总笔数:10|总金额:10776.26|总份额:7914.46
销售机构订单号|申请单编号|交易账号|基金代码|机构代码|业务类型|交易时间|申请份额|申请金额|个人/机构标识
20250813102856000001|2025081310285601|76950647991594577|220515|888|024|20250813102856|1781.03||1
...
```

**比较文件**（compare_file.txt）：
```
总笔数:9|总金额:9292.34|总份额:10654.62
销售机构订单号|申请单编号|交易账号|基金代码|机构代码|业务类型|交易时间|申请份额|申请金额|个人/机构标识
20250813102856000001|2025081310285601|76950647991594577|220515|888|024|20250813102856|1518.11||1
...
```

**比对结果**（difference.txt）：
- 缺失记录：3条（存在于标准文件但不存在于比较文件）
- 新增记录：2条（存在于比较文件但不存在于标准文件）
- 修改记录：5条（相同订单号但申请份额或申请金额不同）

## 性能提示

1. **文件大小判断**：对于大于可用内存的文件，请启用外部排序
2. **主键比对**：当需要按业务主键对比而非行对行对比时启用
3. **排除规则**：对于时间戳等不关心的字段，应使用排除规则
4. **单线程模式**：在低配置机器上可考虑启用

## 常见问题

### 1. 比对速度慢
- 检查是否启用了外部排序（大文件建议启用）
- 考虑单线程模式是否被错误启用

### 2. 内存占用过高
- 对于大文件，确保启用了外部排序
- 临时文件会占用磁盘空间

### 3. 正则表达式错误
- 检查语法是否正确
- 使用在线工具测试正则表达式

### 4. 结果不符合预期
- 确认主键正则表达式正确提取了业务主键
- 检查是否需要启用"忽略出现次数"
