# 大文件快速高效比对工具 - 设计方案

## 1. 架构设计

### 1.1 整体架构
- **前端**: Vue.js 3 + TypeScript + Tauri
- **后端**: Rust + Tauri API
- **通信**: 事件驱动模型，前后端通过Tauri事件通信
- **存储**: 本地存储配置信息（store.json）

### 1.2 技术栈选型
- **GUI框架**: Tauri (Rust + Web技术)
- **并行计算**: Rayon (Rust)
- **哈希算法**: GxHash (高性能哈希)
- **外部排序**: extsort (外部存储排序)
- **内存映射**: memmap2 (大文件内存映射)
- **字符串处理**: memchr (快速字符查找)

## 2. 核心模块设计

### 2.1 文件处理模块 (`file_processing.rs`)
#### 外部存储模式 (`external/file_processing.rs`)
- **内存映射**: 使用`mmap`实现文件零拷贝读取
- **并行分块**: 将大文件切分为可管理的块
- **哈希分区**: 使用哈希值将文件行分配到256个分区
- **序列化存储**: 自定义`HashOffset`结构体实现序列化

### 2.2 比较算法模块 (`comparison.rs`)
#### 外部存储模式 (`external/comparison.rs`)
- **双文件并行处理**: 同时处理两个输入文件
- **两阶段算法**:
  - 阶段1: 文件分区和哈希生成
  - 阶段2: 哈希比较和唯一行提取
- **临时文件管理**: 自动清理临时目录
- **进度追踪**: 分阶段报告处理进度

### 2.3 前端组件模块 (`App.vue`)
- **状态管理**: Vue 3 Composition API
- **事件监听**: 监听后端发送的进度和结果事件
- **配置持久化**: 使用Tauri Store插件
- **响应式UI**: 实时更新进度和结果显示

## 3. 核心算法设计

### 3.1 外部排序算法
```
1. 文件A: 切分 -> 哈希分区 -> 存储到临时文件
2. 文件B: 切分 -> 哈希分区 -> 存储到临时文件
3. 分区对比: 对比相同分区的哈希值
4. 唯一行提取: 根据哈希偏移位置提取原始行
```

### 3.2 主键匹配算法
- **主键提取**: 使用正则表达式提取业务主键
- **哈希映射**: 构建主键到行数据的映射
- **三路比较**: 
  - 修改: 主键相同但内容不同
  - 缺失: 存在于A但不存在于B
  - 新增: 存在于B但不存在于A

### 3.3 性能优化策略
- **并行处理**: 使用Rayon的并行迭代器
- **内存映射**: 使用mmap避免数据拷贝
- **外部排序**: 适用于超大文件的磁盘排序
- **缓存优化**: 优化数据结构减少内存访问

## 4. 通信机制设计

### 4.1 前后端通信
- **命令调用**: `start_comparison`启动比对
- **事件发射**: 
  - `progress`: 进度更新
  - `unique_line`: 发现唯一行
  - `step_completed`: 步骤完成
  - `comparison_finished`: 比对完成

### 4.2 数据结构定义 (`payloads.rs`)
- **ProgressPayload**: 进度信息
- **UniqueLinePayload**: 唯一行数据
- **StepDetailPayload**: 步骤耗时
- **ComparisonFinishedPayload**: 完成通知

## 5. 配置选项设计

### 5.1 算法配置
- **useExternalSort**: 切换外部/内部排序模式
- **ignoreOccurences**: 忽略重复记录的计数
- **useSingleThread**: 单线程处理模式
- **ignoreLineNumber**: 忽略行号位置信息

### 5.2 正则表达式功能
- **primaryKeyRegex**: 业务主键提取表达式
- **excludeRegex**: 需要排除的行的表达式
- **历史管理**: 保存常用正则表达式历史

## 6. 用户界面设计

### 6.1 界面布局
- **文件选择区**: 文件A和文件B选择
- **配置区**: 算法选项和正则表达式配置
- **进度区**: 实时进度显示
- **结果区**: 差异结果显示

### 6.2 多语言支持
- **语言选择**: 英语、中文、日语、韩语
- **翻译文件**: `i18n.ts`定义所有界面文本
- **动态切换**: 支持运行时语言切换

## 7. 性能特征

### 7.1 时间复杂度
- **传统diff**: O(n + m) 其中n,m是两个文件的行数
- **外部排序**: O(n log n) 基于外部排序算法
- **内存模式**: O(n + m) 基于哈希表的线性时间

### 7.2 空间复杂度
- **外部排序**: O(√n) 临时文件存储，取决于分区数
- **内存模式**: O(n + m) 完整的哈希表存储

### 7.3 并行度
- **文件读取**: 并行处理两个输入文件
- **哈希计算**: 并行处理文件分区
- **结果提取**: 并行提取唯一行

## 8. 错误处理与恢复

### 8.1 错误类型
- **文件访问错误**: 权限或不存在
- **内存不足**: 自动切换到外部模式
- **正则表达式错误**: 前端输入验证

### 8.2 恢复机制
- **自动清理**: 后台线程清理临时文件
- **状态重置**: 比对完成后重置所有状态
- **事件解耦**: 异常情况下保持组件状态独立

## 9. 扩展性设计

### 9.1 模块化架构
- **外部/内部模块分离**: 易于扩展新的处理模式
- **插件化设计**: Tauri插件支持新功能
- **配置驱动**: 通过配置选项控制算法行为

### 9.2 扩展接口
- **新算法**: 可添加新的比较算法
- **输出格式**: 支持多种结果输出格式
- **数据源**: 可扩展支持数据库或其他数据源
